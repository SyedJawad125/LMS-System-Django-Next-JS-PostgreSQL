In this project, an LMS system was developed along with an Agentic LLM-based RAG architecture. The backend is built with Django and PostgreSQL, while the frontend is developed using Next.js. For the RAG implementation, PostgreSQL is integrated with a vector store, and ChromaDB is used for efficient vector storage and retrieval.
